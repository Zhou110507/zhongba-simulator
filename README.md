阶段 A、B 已验收；第三阶段旋转模型已接入练习台。当前在第四阶段之前增补了中八规则对局与自由球台，等待用户验收。435 项 Python、18 项 JavaScript 测试通过，另有 84 组瞄准对照与 108 组文献公式控制实验。使用说明、规则版本和物理范围见 [中八规则对局与自由球台验收](docs/中八规则对局与自由球台验收.md)。历史验收记录保留在 `docs/`。本次进一步完成拖动、计算及回放优化，并加入可复现随机微隙；见 [性能优化与实摆微隙复核](docs/性能优化与实摆微隙复核.md)。本轮修正球堆弹性传递并在中八模式自动执行判罚、进入下一杆，见 [开球弹性传递与自动继续复核](docs/开球弹性传递与自动继续复核.md)。

## 打开练习台

在项目根目录双击 `启动练习台.cmd`，或运行：

```powershell
python -m billiards.webapp --port 8766 --open
```

浏览器地址为 `http://127.0.0.1:8766/`，服务仅监听本机。新启动服务时请保持终端运行，按 Ctrl+C 停止；已有同版本服务则直接打开页面。换新机器时，在项目根目录先安装依赖：

```powershell
python -m pip install -e ".[test]"
```

运行依赖 Python 3.11+ 和 NumPy；测试使用 pytest。界面不使用外部 CDN。Node 用于开发时的 JavaScript 检查，无须安装前端依赖。本次直接使用已有 Python 3.13.5、NumPy 2.1.3 和浏览器，没有安装额外框架。

## 练习方式

页面顶部可切换「中八规则对局」与「自由球台」。规则模式按 CBSA 2017 公开规则摆球、轮换、分组、判罚自由球和胜负，球停后自动执行判罚并继续，普通犯规直接进入自由球摆放；可单独回看上一杆。本地双人对局自动保存在本机。自由球台可选 0–15 颗目标球或具体球号，并输入白球位置。

1. 选择角袋直球、中袋直球、低杆、低杆分离角、高杆、碰库、中力走台或自由摆球预设。
2. 在瞄准模式点击球桌确定方向，也可输入角度；调整力度和白球击点。高低杆、左右击点通过球杆冲量产生旋转。
3. 点击「预览路线」或「出杆」。可暂停、慢放、拖动时间轴。中八正式出杆结束后自动继续；自由练习可选择「回到出杆前」或「继续下一杆」。取得自由球时按界面提示摆放白球。
4. 在摆球模式拖动球或输入毫米坐标，可增删目标球、撤销，最多一颗白球和 15 颗目标球。
5. 「保存场景」导出包含完整初态、球桌、物理、球杆参数及版本的 JSON；「导入场景」校验后还原。同版本初态可复现整杆。浏览器也在本机保存最近场景；版本不匹配时保留备份，不静默套用新模型。

拖动时方向线与虚线白球同步更新，首段解析计算考虑球半径、圆弧库边、停距及先落袋；完整路线在点击预览或出杆时计算，拖动瞄准不会提交整杆请求。虚线圆表示首次接触前白球位置，亮点表示表面接触点；力度不够则显示实际停点。低杆预设会显示真实触球切角、碰前倒旋比和恢复滚动后的回拉偏角。预览、出杆和回放共用物理内核；动画帧率不决定计算步长。旧阶段 A 物理验收台从页面内链接进入，初次使用需执行 `python -m tools.build_acceptance` 生成历史页面。

## 器材与适用范围

第三阶段新增[旋转与碰撞实验台](http://127.0.0.1:8766/lab)，也可从练习页顶部进入。支持碰薄带偏、侧旋传递、齿合、高低杆及左右旋碰库对照；可导入测量 JSON 拟合台呢与球球法向恢复参数并导出。示例数据为合成数据，不是实测。模型与范围、标定格式、自验记录见[第三阶段实施与验收](docs/第三阶段实施与验收.md)。第二阶段已验收，第四阶段走位反算尚未开始。

练习台采用乔氏公开台型 2540 × 1260 mm，球径 57.15 mm，163 g 是允许范围内的模拟选值。规则对局和阶段 A 封闭矩形实验采用 CBSA 2017 的 2540 × 1270 mm。规格来源见 [中八器材规格核查](docs/中八器材规格核查.md)。

角袋最小开口 84 mm、中袋 86 mm 参考 GB/T 22751—2008 原文的中式台球桌尺寸表，不能代表所有当前比赛用桌。**袋角与下球线是两组不同的弧线：**袋角半径为角袋 30 mm、中袋 40 mm；下球线圆弧半径为角袋 45 mm、中袋 47 mm，角袋中央前沿距张口入口 10 mm，两中袋前沿位于直库接触线内侧 15 mm（v6 工程修正）。球心进入下球线弧内且通过袋角净空即记入袋，弧内静止球也会落袋。袋角和下球线为不同曲线的依据来自量规专利及石板制造商，具体半径仍为工程配置，不能冒称标准或实测值，也未模拟三维下落及跳出台。六袋用与直库相切的解析袋角，最小喉口不变。参数与来源记录在 `configs/prototype_play.json`；画面、碰撞及下球线使用共享几何。

台呢不限定品牌：练习台滑动摩擦 0.18 参考实测区间低端，滚动减速度系数 0.007 为文献范围内的较快台面选值。杆头速度范围扩大到 5 m/s，50% 中杆白球约 3.30 m/s。新配置属于有依据的通用微调，尚未进行单张球桌的联合实测标定。球球采用随接触表面滑速变化的水平摩擦投影，包含带偏及侧旋传递，暂不包含竖直冲量及高低旋向目标球转移；球库沿用阶段 A v3 的旋转耦合研究基准。能量恢复参数 0.98 不是法向速度比，也不是乔氏实测值，来源与验证见 [05 碰库复核](docs/05薄厚球碰库专项复核.md)。

当前为水平出杆近似，击点限制 0.55 R；不模拟杆身偏移、跳球或扎杆。已支持紧密十五球开球和明确版本的比赛判罚；开阔台面球堆使用短时 Hertz 弹性接触，持续贴库等复杂接触仍采用工程近似并有限制，走位反算尚未开始。不支持的接触会显示限制，不能将未完成仿真应用为下一杆。

## 结构

- `billiards/model.py`、`motion.py`、`engine.py`：不可变状态、解析运动与连续碰撞调度。
- `billiards/rules.py`、`game.py`：版本化规则判罚、服务端对局和自由球台生成。
- `billiards/elastic.py`：短时 Hertz 弹性接触、冲击传播及无损微步记录。
- `billiards/cluster.py`：历史及连接库边的确定性冲量近似。
- `billiards/cushion.py`：库边与台呢双接触冲量及旋转耦合。
- `billiards/pockets.py`：六袋、圆弧袋角、连续检测及落袋事件；提供界面共享轮廓。
- `billiards/cue.py`：水平杆头冲量及击点到旋转的映射。
- `billiards/play.py`：同模型出杆、预设、版本化场景和复现校验。
- `billiards/shot_analysis.py`、`web/shot-guide.js`：从实际事件解释分离角与首次接触位置。
- `billiards/webapp.py`、`web/`：本机 HTTP 服务与 Canvas 练习界面。
- `configs/`：带版本和来源的器材、物理及原型球杆/袋口配置。
- `tests/`、`tools/`：解析基准、碰撞回归、接口验证与验收材料构建。
- [框架设计](台球模拟软件框架设计.md)：阶段划分与第二阶段技术选型决定。

物理背景参考 [Evan Kiefl 的台球推导](https://ekiefl.github.io/2020/04/24/pooltool-theory/)；当前为独立实现，没有引入 pooltool。测试通过说明符合声明模型，实桌误差需后续独立标定。
