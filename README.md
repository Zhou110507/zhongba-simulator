当前交付：独立物理内核和预设场景验收工具。阶段 A 根据用户的碰库反馈完成 v2 返修和 05 专项复核，等待重新验收；尚未进入阶段 B。当前 116 项测试通过，动力学参数尚未针对乔氏 + 利百文实桌标定。

## 直接验收

先运行下面的构建命令，再用浏览器打开 `artifacts/phase-a/验收演示.html`，或直接打开 `05-薄厚球专项复核.html`。生成的文件内含全部轨迹，可离线回放。

主页面默认进入原 06 的修正版 06A，专项入口默认进入 05。共有十个选项，支持播放、暂停、重播、0.25～2 倍速和拖动时间轴。05 和 06 使用相同的旋转耦合碰库内核；05B 与 06C 是无摩擦、完全弹性的理想对照，分别在 2.4 s 和 0.8 s 主动截断，其余场景均模拟到自然停止。页首显示构建标识，侧栏显示当前碰库模型，避免混淆版本。

当前记录见 `docs/碰库模型复核与乔氏利百文标定.md`，旧验收报告仅作历史留档。中八尺寸与袋口来源见 `docs/中八器材规格核查.md`。

## 开发与复验

本次使用当前机器已有的 Python 3.13.5、NumPy 2.1.3、pytest，没有修改系统环境或下载依赖。

从项目根目录执行：

```powershell
python -m pytest -q
python -m tools.build_acceptance
python -m tools.audit_cushion
python -m tools.audit_cut
```

第一条运行测试；第二条重建演示与轨迹；后两条保存 06 和 05 的角度、旋转及步数收敛对照。生成的 `artifacts/` 不纳入版本库，可随时重建。依赖声明在 `pyproject.toml`，如换新机器，可运行 `python -m pip install -e ".[test]"`。阶段 A 不依赖 PySide6。仓库含 GitHub Actions 配置，推送后运行相同测试和演示构建。

如希望通过本地 HTTP 打开：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8765/artifacts/phase-a/验收演示.html`；终端按 Ctrl+C 停止。服务器只监听本机。

## 结构

- `billiards/model.py`：不可变的球、球桌和物理参数，输入校验。
- `billiards/motion.py`：解析滑动、滚动、自旋衰减及状态转移。
- `billiards/engine.py`：连续碰撞检测、事件调度、碰撞处理、轨迹采样与导出。
- `billiards/cushion.py`：库边与台呢双接触冲量、摩擦与旋转耦合。
- `billiards/diagnostics.py`：碰库前、瞬时反弹及恢复滚动后的角度。
- `billiards/equipment.py`：读取带版本与来源的器材配置。
- `billiards/scenarios.py`：十个可复现选项，含 05B 与 06A/B/C 碰库对照。
- `configs/chinese_eight_ball.json`：中八器材规格及待核实袋口数据。
- `tests/`：物理解析基准、守恒、边界、随机场景和器材配置检查。
- `tools/`：验收产物构建器与回放页面模板。
- `artifacts/phase-a/`：可直接查看的演示、轨迹与测试证据。

## 适用范围

默认使用 CBSA 2017 公布的内沿 2540 × 1270 mm、球径 57.15 mm；另列 WPA Heyball 2025 与乔氏 Q8 的 2540 × 1260 mm 配置。163 g 是规则范围内的模拟选值，摩擦和恢复系数尚未针对真实球桌标定。

阶段 A 为封闭矩形测试台；**没有袋口、自由出杆或走位反算**。高低杆示例直接设定白球初速度和旋转。球球接触仍不含切向摩擦；球库已加入研究用的摩擦与旋转耦合，但没有乔氏实测精度保证。复杂多接触和零速度持续挤压返回暂不支持状态，不能用于完整开球球堆仿真。

## 物理模型

均匀实心球转动惯量为 `I = 2mR²/5`。台面接触点滑动速度为 `u = (vx − Rωy, vy + Rωx)`。

滑动阶段采用库仑摩擦，平动加速度 `a = −μs g u/|u|`，水平角加速度为 `(5ay/(2R), −5ax/(2R))`；滑动转滚动的时间为 `2|u|/(7μs g)`。纯滚动采用有效恒定减速度 `μr g`，停止时间为 `|v|/(μr g)`，并保持无滑动约束。竖直轴旋转以单独的经验角减速度衰减。

球球采用法向恢复冲量；默认库边使用双接触冲量近似，同时更新平动和三维旋转。旧平库反转模型仅保留为 `frictionless` 对照。相邻事件间的位置为二次函数，球球接触时刻由距离平方的四次多项式求根，库边接触用二次/一次方程；只接受相互接近的接触根。

模型参考：[Evan Kiefl 的台球物理推导](https://ekiefl.github.io/2020/04/24/pooltool-theory/)。当前实现为本项目独立代码，未引入 pooltool 依赖。数值基准的通过仅说明实现符合所声明模型，不等于已达到真实中八球桌的相同精度。
