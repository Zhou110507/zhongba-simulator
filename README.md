# 中八练习台

阶段 A–D 已验收。第五阶段将自由球台分为“练习台”和“反算台”。反算默认先直接击打目标球进袋，再调整走位，允许分离后吃库；目标区域可选 60、80、100、120 mm 半径，白球压线即成功。专项解球仍支持首碰前一库、两库。当前流程与复核见 [进球优先反算复核](docs/进球优先反算复核.md)，页面拆分与专项算法见 [第五阶段实施与验收](docs/第五阶段实施与验收.md)。历史器材、规则、摩擦、袋角、低杆与性能复核保留在 `docs/`。

## 打开练习台

在项目根目录双击 `启动练习台.cmd`，或运行：

```powershell
python -m billiards.webapp --port 8766 --open
```

请双击项目根目录的 `启动练习台.cmd`，不要直接双击 `web/index.html`；直接打开 HTML 不会启动物理服务。启动器将服务放到独立后台，确认就绪后自动打开实际地址，启动窗口关闭也能继续使用。服务仅监听本机，默认尝试 8766 附近端口，复用同版本服务并避开旧服务。若手动运行上面的 `billiards.webapp` 命令，则仍需保持该终端运行；也可运行 `python -m billiards.launcher` 使用后台启动。换新机器时，在项目根目录先安装依赖：

```powershell
python -m pip install -e ".[test]"
```

运行依赖 Python 3.11+ 和 NumPy；测试使用 pytest。界面不使用外部 CDN。Node 用于开发时的 JavaScript 检查，无须安装前端依赖。本次直接使用已有 Python 3.13.5、NumPy 2.1.3 和浏览器，没有安装额外框架。

## 练习方式

页面顶部可切换「练习台」「反算台」与「中八规则对局」。练习台与反算台共用自由球位、出杆参数与预览，切换不会重摆球。规则模式按 CBSA 2017 公开规则摆球、轮换、分组、判罚自由球和胜负，球停后自动执行判罚并继续，普通犯规直接进入自由球摆放；可单独回看上一杆。本地双人对局自动保存在本机。练习台与反算台都可选 0–15 颗目标球；展开“白球位置与具体球号”可指定编号与白球位置；“一键摆满15球”直接生成 15 颗目标球＋1 颗白球。

1. 选择角袋直球、中袋直球、低杆、低杆分离角、高杆、碰库、中力走台或自由摆球预设。
2. 在瞄准模式点击球桌确定方向，也可输入角度；调整力度和白球击点。高低杆、左右击点通过球杆冲量产生旋转。
3. 点击「预览路线」或「出杆」。可暂停、慢放、拖动时间轴。中八正式出杆结束后自动继续；自由练习可选择「回到出杆前」或「继续下一杆」。取得自由球时按界面提示摆放白球。中八模式不显示球尾迹，自由球台保留可选尾迹。
4. 在摆球模式拖动球或输入毫米坐标，可增删目标球、撤销，最多一颗白球和 15 颗目标球。
5. 「保存场景」导出包含完整初态、球桌、物理、球杆参数及版本的 JSON；「导入场景」校验后还原。同版本初态可复现整杆。浏览器也在本机保存最近场景；版本不匹配时保留备份，不静默套用新模型。

拖动时方向线与虚线白球同步更新，首段解析计算考虑球半径、圆弧库边、停距及先落袋；完整路线在点击预览或出杆时计算，拖动瞄准不会提交整杆请求。虚线圆表示首次接触前白球位置，亮点表示表面接触点；力度不够则显示实际停点。低杆预设会显示真实触球切角、碰前倒旋比和恢复滚动后的回拉偏角，并显示出杆到碰前的旋转变化与球底滑速。倒旋变零和滑动结束是不同的时刻；调整低杆时会提示直线无遮挡条件下的两种距离。预览、出杆和回放共用物理内核；动画帧率不决定计算步长。旧阶段 A 物理验收台从页面内链接进入，初次使用需执行 `python -m tools.build_acceptance` 生成历史页面。

## 反算台

在顶部切换“反算台”，默认使用“普通进球＋走位”：白球首碰前不吃库，目标球按指定袋或任意合适球袋直接进袋，随后规划白球走位。先校正普通进球的瞄点，再搜索力度、高低杆和袋口允许范围内的厚薄微调。默认无左右塞，也可选择必要时少量左右塞或进阶击点。范围内优先少库、少塞和较轻的杆法，再结合实际完成的模型扰动检查排序。

输入目标区域的中心毫米坐标，或在台面选取位置。半径为 60、80、100、120 mm 四档，默认 100 mm。白球与目标圆相交或相切即成功：球心距区域中心不超过“区域半径＋28.575 mm”。显示的球心距离仍是实际距离，不把压线成功写成零误差。进球、首碰、白球不落袋等硬性条件仍须同时成立。允许白球分离后吃库，可指定首碰后恰好 0–4 库及全杆碰库上限。

选择“专项走位／解球”后，才开放首碰前一库、两库或自动比较 0–2 库，指定库边顺序及不要求进袋的任务。当前场景的全部球始终参与计算；不允许白球再碰其他球时，该条件作为硬性限制。

后台搜索支持取消：直击最多 480 次，含碰库的搜索最多 1000 次，总计包括候选、复验与扰动；已违反硬性约束的事件前缀可以提前剔除。只有完整停球且通过完整轨迹复验的参数才会推荐。结果显示首碰前后实际库边、停点偏差、杆法与计算量；范围外方案标为近似。各方案最多检查方向 ±0.05°、杆速 ±2%、左右/高低击点 ±0.01 R 的八项模型扰动，显示实际完成数与通过项数；这不是真人成功率。

可选“普通进球走位示例”“进球走位：分离后吃一库”，专项模式另有一库绕障、两库解球示例。示例提供球位与目标，不向搜索器提供杆法答案。“应用并预览”保持球位并调用普通预览；切回练习台可微调杆法。“导出反算记录”包含原始任务、全部候选、模型版本和性能数据，供复核。改变球位、终点或限制后旧结果失效，离开反算台取消后台任务。

搜索有时间与计算量预算，不保证全局最优或穷尽线路；预算内未找到不代表物理不可达。首碰前最多两库、全杆最多四库；尚不支持任意长度路线、跳球/扎杆或多杆规划。物理系数、球桌尺寸和最大杆速沿用已验收配置，未为反算调整。

## 可选 AI 对手（四档出杆稳定性 v6）

中八对局提供“入门、进阶、高手、最强（训练原版）”四档，默认最强。各档共用同一个最强规划器，只在实际出杆时加入不同尺度的方向及杆头速度正态误差；最强不加误差，保留原表现。可在“上一杆出杆记录”核对计划与实际参数；低档实际停点偏离时按真实台面重新续算。详见 [四档参数与验收](docs/AI四档出杆稳定性验收.md)。

在“中八规则对局”选择“对局方式”，可将任意一方交给 AI，默认仍是本地双人。点击“体验三球清台（新练习局）”可直接建立三颗本方球＋黑八残局；原对局记录仍保存在本机。右侧“查看 AI 思路”展示球序、袋口、预测白球停点、杆法和连接球解释，随后可“执行当前这一杆”，或勾选“自动对打”。取消自动对打可停在下一杆前；切换本地双人可手动接管。AI 提供离线开球、选球、规则选择和自由球摆放，本方三球以内尝试清台，更多球时前瞻三杆。停球与预测一致时复用后续路线，失配则重新计算。

局面评价网络已用本软件生成的普通杆法残局进行训练，数据、权重、训练曲线与留出对照随仓库提供，见 [当前训练包](training/ai_stage3/README.md)；[第一阶段说明](docs/AI清台第一阶段训练与验收.md)保留历史验收记录。评分考虑适中距离、切角、可用线路、架杆空间和后续衔接；后斯诺、近库低杆、过近二次击打风险在候选搜索前排除。近库不是不分方向地禁止低杆：只有后方杆线遇近库时才采用轻柔高杆限制；沿库方向且后方空间充足时可考虑低杆。球杆空间与击点限制为 AI 独立工程策略，不改手动出杆、既有反算或物理参数。

当前模型兼顾进球好打度与走位代价，允许最多五库、高低杆与适度加塞换取更舒服的下一球；空心入袋有小幅加分，有利的借袋角仍保留。允许首碰合法目标后的走位借碰和 K 球，含对方球、黑八；提前进黑八等仍由原规则否决。没有合适进攻时尝试多库解球／防守。自定义残局可移动、添加／移除全部球，选择 AI 球组并保存／导入，原对局保留。

开球用 150 个固定方案在随机正微隙（0.10–0.50 mm）球堆上离线筛选，实战不读取球堆、不在线搜索下球；只按局号选择已学方案。两个方案独立测试分别进球 10/24、6/24，样本很小，不代表实桌概率。当前采用持续三杆前瞻：算好 1、2、3 后，执行第 1 杆时保留 2、3，从第 3 杆预测停点补第 4 杆；执行第 2 杆时再补第 5 杆。补算期间已有杆仍可执行，已知前序不重搜；执行追上补算时接续同一任务。所有球位、规则和模型一致才复用，预算不足或无合法进攻不保证始终补满。见 [持续前瞻复核](docs/AI持续前瞻与队尾补算验收.md)。

已验证推荐杆通过完整停球和原规则判定；若预算内连合法解球也未找到，仍提供标明可能犯规的有界尝试，不再因无进攻路线而弃杆。用户取消或仿真未完成不会提交半杆。不支持抬杆、跳球、扎杆。逐杆微扰记录不作为真人概率，不声称职业水平或任意局面必清台。训练与独立整合演练见 [v4训练包](training/ai_stage3/README.md) 和 [部署复核](docs/AI开球解球借碰与缓存训练验收.md)。

## 器材与物理范围

第三阶段新增[旋转与碰撞实验台](http://127.0.0.1:8766/lab)，也可从练习页顶部进入。支持碰薄带偏、侧旋传递、齿合、高低杆及左右旋碰库对照；可导入测量 JSON 拟合台呢与球球法向恢复参数并导出。示例数据为合成数据，不是实测。模型与范围、标定格式、自验记录见[第三阶段实施与验收](docs/第三阶段实施与验收.md)。第五阶段扩展反算已接入独立反算台。

练习台采用乔氏公开台型 2540 × 1260 mm，球径 57.15 mm，163 g 是允许范围内的模拟选值。规则对局和阶段 A 封闭矩形实验采用 CBSA 2017 的 2540 × 1270 mm。规格来源见 [中八器材规格核查](docs/中八器材规格核查.md)。

角袋最小开口 84 mm、中袋 86 mm 参考 GB/T 22751—2008 原文的中式台球桌尺寸表，不能代表所有当前比赛用桌。**袋角与下球线是两组不同的弧线：**袋角半径为角袋 30 mm、中袋 40 mm；下球线圆弧半径为角袋 45 mm、中袋 47 mm，角袋中央前沿距张口入口 10 mm，两中袋前沿位于直库接触线内侧 15 mm（v6 工程修正）。球心进入下球线弧内且通过袋角净空即记入袋，弧内静止球也会落袋。袋角和下球线为不同曲线的依据来自量规专利及石板制造商，具体半径仍为工程配置，不能冒称标准或实测值，也未模拟三维下落及跳出台。六袋用与直库相切的解析袋角，最小喉口不变。参数与来源记录在 `configs/prototype_play.json`；画面、碰撞及下球线使用共享几何。

台呢不限定品牌：练习台滑动摩擦 0.18 参考实测区间低端，滚动减速度系数 0.007 为文献范围内的较快台面选值。杆头速度范围扩大到 5 m/s，50% 中杆白球约 3.30 m/s。新配置属于有依据的通用微调，尚未进行单张球桌的联合实测标定。球球采用随接触表面滑速变化的水平摩擦投影，包含带偏及侧旋传递，暂不包含竖直冲量及高低旋向目标球转移；球库沿用阶段 A v3 的旋转耦合研究基准。能量恢复参数 0.98 不是法向速度比，也不是乔氏实测值，来源与验证见 [05 碰库复核](docs/05薄厚球碰库专项复核.md)。

当前为水平出杆近似，击点限制 0.55 R；不模拟杆身偏移、跳球或扎杆。已支持紧密十五球开球和明确版本的比赛判罚；开阔台面球堆使用短时 Hertz 弹性接触，持续贴库等复杂接触仍采用工程近似并有限制，扩展走位反算位于独立反算台。不支持的接触会显示限制，不能将未完成仿真应用为下一杆。

## 结构

- `billiards/planner.py`、`planner_pot.py`、`planner_routes.py`、`planner_examples.py`、`planner_jobs.py`、`web/planner.js`：进球优先与专项反算、硬约束复验、后台取消与自由球台集成。
- `billiards/model.py`、`motion.py`、`engine.py`：不可变状态、解析运动与连续碰撞调度。
- `billiards/rules.py`、`game.py`：版本化规则判罚、服务端对局和自由球台生成。
- `billiards/elastic.py`：短时 Hertz 弹性接触、冲击传播及无损微步记录。
- `billiards/cluster.py`：历史及连接库边的确定性冲量近似。
- `billiards/cushion.py`：库边与台呢双接触冲量及旋转耦合。
- `billiards/pockets.py`：六袋、圆弧袋角、连续检测及落袋事件；提供界面共享轮廓。
- `billiards/cue.py`：水平杆头冲量及击点到旋转的映射。
- `billiards/play.py`：同模型出杆、预设、版本化场景和复现校验。
- `billiards/shot_analysis.py`、`web/shot-guide.js`：从实际事件解释分离角与首次接触位置。
- `billiards/webapp.py`、`web/`：本机 HTTP 服务与 Canvas 练习界面。
- `configs/`：带版本和来源的器材、物理及原型球杆/袋口配置。
- `tests/`、`tools/`：解析基准、碰撞回归、接口验证与验收材料构建。
- [框架设计](台球模拟软件框架设计.md)：阶段划分与第二阶段技术选型决定。

物理背景参考 [Evan Kiefl 的台球推导](https://ekiefl.github.io/2020/04/24/pooltool-theory/)；当前为独立实现，没有引入 pooltool。测试通过说明符合声明模型，实桌误差需后续独立标定。
