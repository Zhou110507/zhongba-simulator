# 中八练习台

阶段 A 于 2026-10-20 经用户确认通过；阶段 B「二维可玩原型」继续处理用户反馈，等待验收。当前 v3 共 209 项 Python 测试与 4 项 JavaScript 接触显示测试通过，增加低杆分离角复核、六袋连续圆弧及物理事件驱动的瞄准圆。详见 [低杆分离角与六袋几何复核](docs/低杆分离角与六袋几何复核.md)。此前的 [台呢阻力与力度范围复核](docs/台呢阻力与力度范围复核.md) 和 [第二阶段验收报告](docs/第二阶段验收报告.md) 留档。

## 打开练习台

在项目根目录双击 `启动练习台.cmd`，或运行：

```powershell
python -m billiards.webapp --port 8766 --open
```

浏览器地址为 `http://127.0.0.1:8766/`，服务仅监听本机。新启动服务时请保持终端运行，按 Ctrl+C 停止；已有同版本服务则直接打开页面。换新机器时，在项目根目录先安装依赖：

```powershell
python -m pip install -e ".[test]"
```

运行依赖 Python 3.11+ 和 NumPy；测试使用 pytest。界面不使用外部 CDN。Node 用于开发时的 JavaScript 检查，无须安装前端依赖。本次直接使用已有 Python 3.13.5、NumPy 2.1.3 和浏览器，没有安装额外框架。

## 练习方式

1. 选择角袋直球、中袋直球、低杆、低杆分离角、高杆、碰库、中力走台或自由摆球预设。
2. 在瞄准模式点击球桌确定方向，也可输入角度；调整力度和白球击点。高低杆、左右击点通过球杆冲量产生旋转。
3. 点击「预览路线」或「出杆」。可暂停、慢放、拖动时间轴、重播，再选择「回到出杆前」或「继续下一杆」。白球落袋后需先摆回球桌。
4. 在摆球模式拖动球或输入毫米坐标，可增删目标球、撤销，最多一颗白球和 15 颗目标球。
5. 「保存场景」导出包含完整初态、球桌、物理、球杆参数及版本的 JSON；「导入场景」校验后还原。同版本初态可复现整杆。浏览器也在本机保存最近场景；版本不匹配时保留备份，不静默套用新模型。

虚线圆是引擎记录的首次接触前白球位置，亮点是真实表面接触点；力度不够则显示实际停点。低杆预设会显示真实触球切角、碰前倒旋比和恢复滚动后的回拉偏角。预览、出杆和回放共用物理内核；动画帧率不决定计算步长。旧阶段 A 物理验收台从页面内链接进入，初次使用需执行 `python -m tools.build_acceptance` 生成历史页面。

## 器材与适用范围

练习台采用乔氏公开台型 2540 × 1260 mm，球径 57.15 mm，163 g 是允许范围内的模拟选值。阶段 A 的封闭矩形实验保留 CBSA 2017 的 2540 × 1270 mm。规格来源见 [中八器材规格核查](docs/中八器材规格核查.md)。

角袋最小开口 84 mm、中袋 86 mm 参考 GB/T 22751—2008 原文的中式台球桌尺寸表，不能代表所有当前比赛用桌。**圆弧轮廓仍为工程配置：**角袋半径 30 mm、中袋 40 mm，落袋线深度 45 mm、袋道延伸 90 mm。尚无可信的中八橡胶鼻口弧线图纸；这些半径不是标准值或实测值。六袋均用与直库相切的解析圆弧，增大半径不会暗中扩大最小喉口。参数与来源记录在 `configs/prototype_play.json`；画面与碰撞共享轮廓，球越过袋道落袋线才进袋。

台呢不限定品牌：练习台滑动摩擦 0.18 参考实测区间低端，滚动减速度系数 0.007 为文献范围内的较快台面选值。杆头速度范围扩大到 5 m/s，50% 中杆白球约 3.30 m/s。新配置属于有依据的通用微调，尚未进行单张球桌的联合实测标定。球球暂不含切向摩擦；球库沿用阶段 A v3 的旋转耦合研究基准。能量恢复参数 0.98 不是法向速度比，也不是乔氏实测值，来源与验证见 [05 碰库复核](docs/05薄厚球碰库专项复核.md)。

当前为水平出杆近似，击点限制 0.55 R；不模拟杆身偏移、跳球或扎杆。完整开球球堆、复杂持续多接触、比赛判罚和走位反算属于后续阶段。不支持的接触会显示限制，不能将未完成仿真应用为下一杆。

## 开发与复验

```powershell
python -m pytest -q
python -m tools.verify_phase_b
python -m tools.audit_cloth
python -m tools.audit_draw_angles
python -m tools.build_acceptance
python -m tools.audit_cushion
python -m tools.audit_cut
node --check web/app.js
node tests/shot-guide.test.cjs
```

Python 测试共 209 项，其中原阶段 A 为 122 项，另有 4 项 JavaScript 接触显示测试。B 验证器重建八个预设的初态、完整轨迹和复现检查；A 构建器重建历史离线页面。低杆审计对比五组瞄准偏角与独立解析结果。生成的 `artifacts/` 不纳入版本库，可随时重建。GitHub Actions 运行测试、两阶段构建、台呢/力度对照、低杆角度审计与 JavaScript 检查。每轮代码修改检查完成后同步私有仓库。

## 结构

- `billiards/model.py`、`motion.py`、`engine.py`：不可变状态、解析运动与连续碰撞调度。
- `billiards/cushion.py`：库边与台呢双接触冲量及旋转耦合。
- `billiards/pockets.py`：六袋、圆弧袋角、连续检测及落袋事件；提供界面共享轮廓。
- `billiards/cue.py`：水平杆头冲量及击点到旋转的映射。
- `billiards/play.py`：同模型出杆、预设、版本化场景和复现校验。
- `billiards/shot_analysis.py`、`web/shot-guide.js`：从实际事件解释分离角与首次接触位置。
- `billiards/webapp.py`、`web/`：本机 HTTP 服务与 Canvas 练习界面。
- `configs/`：带版本和来源的器材、物理及原型球杆/袋口配置。
- `tests/`、`tools/`：解析基准、碰撞回归、接口验证与验收材料构建。
- [框架设计](台球模拟软件框架设计.md)：阶段划分与第二阶段技术选型决定。

物理背景参考 [Evan Kiefl 的台球推导](https://ekiefl.github.io/2020/04/24/pooltool-theory/)；当前为独立实现，没有引入 pooltool。测试通过说明符合声明模型，实桌误差需后续独立标定。
