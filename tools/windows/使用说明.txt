中八球房 · Windows 64 位便携版

将整个压缩包解压到一个可写文件夹，双击 Zhongba3D.exe。启动器会打开默认浏览器，地址只在本机使用。可以断网游玩。关闭浏览器后再次双击即可接着打。球局和服务日志保存在本文件夹的 artifacts 中。

第一次打
1. 默认是本地双人对局。按“对局设置”可改为和电脑比赛、选择抢局数或开始新对局。
2. 环绕视角点击台呢瞄准，拖动球台转动镜头，滚轮调远近。数字键 1、2、3 分别为环绕、杆后、俯视。
3. 拖动白球击点，调整力度。左右方向键微调方向，按空格出杆。正式比赛结束每杆后自动判罚，获得自由球时点击球台摆球。
4. 在“自由练习”中载入直球、高低杆或库边预设，可预览轨迹、暂停、拖动时间轴或继续下一杆。
5. “训练工作台”提供自由摆球、场景保存和走位反算。球房采用中台协 2017 版公开规则。

如需查看启动信息，可双击“启动中八3D.cmd”。程序默认使用 8766 附近的空闲端口。首次运行时留出写入存档和日志的权限。

本包附带 CPython 和 NumPy。Python 许可证保存在 runtime/LICENSE.txt，NumPy 许可证保存在 runtime/Lib/site-packages/numpy-*.dist-info 中。
