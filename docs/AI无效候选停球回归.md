# AI 无效候选停球回归

版本 `validated-ai-candidates-v7`，基于 `49f77fda2946ea9ea03d17348fa8db1b37ac32b4`。

## 故障与修复

2026-10-22 的实际中八残局在规划后续杆时出现 `Balls 12 and 13 overlap`。已捕获真实失败候选的输入球位及出杆参数：方向 162.9206364161898°、杆头速度 3.2 m/s、高杆 0.5 R。原模拟返回 `stopped`，但 12、13 号球仍重叠约 0.3890487 mm。搜索随后调用下一杆的台面解码时抛出异常，导致整个 AI 任务失败。

共享物理出口现在使用原有 `validate_scene` 检查停球结果。未通过的结果返回 `invalid_final_state`，搜索计入剔除原因并继续寻找其他候选；出杆服务不生成下一杆场景，正式对局不提交、不增加版本。取消、超时和其他未完成状态保留原有含义。

没有放宽 1e-10 m 的既有球间重叠校验容差，没有调整球位、器材尺寸、碰撞参数、力度映射或 AI 权重。本次解决的是无效候选被误认作可继续台面而击穿搜索流程的问题；导致该候选重叠的接触求解路径仍按未完成结果处理，没有宣称已提高接触模型的物理准确性。

## 固定回归与实际复验

真实失败样本保存在 [测试夹具](../tests/fixtures/ai-invalid-final-state.json)，包括原始残局和失败的后续模拟局面；对局编号已替换，历史记录已清空。[回归测试](../tests/test_ai_invalid_final_state.py) 验证：

- 相同真实出杆在完整回放和轻量试算下均识别为未完成，保留原始无效几何以供诊断。
- 搜索剔除该候选后仍可计算另一杆有效结果，不修改源局面。
- 无效结果无法推进或写入持久化对局。
- 重叠、越界、非有限数值三个终态故障均被拦截；既有贴球容差和无效输入拒绝契约不变。

全部 **590 项 Python 测试、45 项前端测试通过**。复现命令：

```powershell
python -m pytest -q
node --test --test-isolation=none tests/shot-guide.test.cjs tests/replay-core.test.cjs tests/table-modes.test.cjs tests/planner.test.cjs tests/ai-opponent.test.cjs
```

界面用相同球位、球权、球组和进阶档创建独立副本复验：281 次模拟，22.24 秒，剔除 3 个无效终态，正常给出 `2 → 6` 的部分续接路线。实际执行第一杆后 2 号合法入袋，无犯规，对局由版本 35 进入 36。进阶档继续按原规则施加出杆误差，没有重抽至进球。上述耗时只是本机这次复验，不是性能保证。

原用户对局仍为版本 35，文件字节未变。实际分析、出杆参数及核对值见 [验证记录](../validation/ai_invalid_final_state.json)。预防同类问题的约定已写入 [AGENTS.md](../AGENTS.md)。

进球后的下一杆也已在界面检查：291 次模拟、22.64 秒，正常给出 `6 → 7` 的续接方案；该方案保留供查看，未继续执行。
