# B 阶段：二维可玩原型

2026-10-20：用户确认第一阶段通过，授权开始第二阶段。该阶段完成后自行复验，再提交用户验收。

## 交付范围

浏览器负责摆球、瞄准、力度和白球击点输入；本地 Python 服务调用阶段 A 已验收的运动与碰库内核。预览、正式出杆和回放共用同一杆计算结果。界面动画帧率不决定物理时间步。

支持拖动与数值摆球、添加/移除目标球、瞄准角度、合法击点圆盘、高低杆与左右击点、出杆、暂停/慢放/时间轴、回到出杆前状态、接着打下一杆、白球落袋后重新摆放，以及版本化场景的保存/导入。完整中八裁判、完整开球球堆和走位反算属于后续阶段。

## 几何与参数边界

- 默认台面为乔氏公开台型 2540 × 1260 mm，球径 57.15 mm；阶段 A 的矩形验收台保留原配置。
- 精确乔氏袋口图纸仍未取得。六袋原型采用独立的试验配置：开口、袋角圆弧、袋道和落袋线均明确记录，不称为标准或实测几何。
- 碰撞检测与画面使用相同的直线/圆弧轮廓。球须经过袋道并越过落袋线才进袋；不能仅因球心接近袋心就删除。
- 杆头接触为水平冲量近似，力度映射、球杆有效质量和皮头恢复参数为可复现的研究配置，尚未针对真人球杆标定。
- 继续使用 v3 旋转耦合碰库基准；不通过修改碰后速度制造高低杆。复杂同时接触返回明确的模型限制状态。

## 自验项目

1. 原阶段 A 测试保持通过。
2. 球杆冲量满足动量/转动关系、对称性、合法击点边界与输入校验；高低杆由碰前旋转自然演化。
3. 六袋中心线路、擦袋角反弹、袋道捕获、白球落袋、球越界与摆球重叠检查。
4. 保存/导入可复现整杆；相同输入得到相同轨迹，渲染采样不改物理结果。
5. 浏览器操作验证预览/出杆/回放/下一杆/撤回，以及编辑期间过期计算结果不会覆盖新场景。
6. 本地接口的载荷边界、错误提示与仅本机监听；旧阶段 A 验收入口仍能打开。
