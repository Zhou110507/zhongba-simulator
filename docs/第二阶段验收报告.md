## 运行与交付

在项目根目录双击 `启动练习台.cmd`，或执行：

```powershell
python -m billiards.webapp --port 8766 --open
```

地址为 `http://127.0.0.1:8766/`。服务仅监听本机；新启动服务时终端需保持运行，按 Ctrl+C 停止。已有同版本服务时启动器直接打开页面。页面可进入阶段 A 历史验收台；换机器需先执行 `python -m tools.build_acceptance` 生成历史页面。

交付了瞄准、角度/力度/击点控制、拖动及毫米坐标摆球、增删目标球、撤销、六个预设、路线预览、出杆、暂停/慢放/时间轴、回到出杆前、下一杆、白球落袋后的重摆和 JSON 场景导入导出。预览与正式出杆均调用同一物理服务，Canvas 按解析轨迹段显示；显示帧率不参与物理积分。

## 几何与精度边界

默认台面使用[乔氏公开台型](https://www.joybilliard.com/billiards-table/)的 2540 × 1260 mm，球径 57.15 mm，球质量 163 g 为允许范围内的模拟选值。乔氏 + 利百文是后续标定目标。

袋口另存于 `configs/prototype_play.json`：角袋/中袋试验开口均 85 mm，圆弧袋角半径 8 mm，落袋线深度 45 mm，袋道延伸 90 mm。**这些是让可玩原型可复现的工程参数，不是已核实的乔氏标准袋口或实测弧度。** 球桌绘制、摆球校验与碰撞使用相同的直线/圆弧实体轮廓；球沿袋道越过落袋线才记录入袋。

球杆采用水平瞬时冲量近似，高低与左右击点产生三维旋转。最大击点 0.55 R、球杆有效质量及力度映射尚未标定；不模拟杆身偏移、抬杆、跳球和扎杆。球球仍采用无切向摩擦模型。库边继续采用 v3 的研究参数（能量恢复基准 0.98），没有以未经核实的数据替换成“乔氏实测摩擦系数”。

复杂同时接触、持续挤压和完整开球球堆尚不支持；遇到这类情况明确显示模型限制，不允许把未完成结果应用为下一杆。完整中八比赛判罚、走位反算和实桌误差标定属于后续阶段。本阶段通过说明实现符合当前模型与交互要求，不代表已经获得实桌精度。

建议用户依次验收角袋/中袋、低杆/高杆、侧旋碰库、自由摆球和保存/导入。收到阶段 B 验收意见后再推进后续阶段。
