## 本次交付

1. 不依赖界面的物理内核：球心二维位置、二维速度、三维角速度，使用 SI 单位与不可变输入。
2. 解析滑动、滑动转滚动、纯滚动停止、侧旋衰减；碰撞后的重新滑动。
3. 连续球球与平库接触检测，孤立球球法向冲量、四边平库反弹、事件时间线。
4. 同一物理模型上的任意时刻采样与 JSON 导出；明确的停止、预算耗尽、暂不支持及异常状态。
5. 七个可复现场景及独立 HTML 验收播放器，支持暂停、重播、速度调整和时间轴。
6. 中八器材规格配置及来源核查，保留不同台型；对未核实袋口曲线明确留空。

## 当前模型的边界

- 台面为中八尺寸的**封闭矩形测试台**；当前没有球袋。
- 初始速度和旋转直接输入；未完成球杆击点、杆头速度和初始状态的换算。
- 球球与球库接触为法向、无切向摩擦模型，尚未实现完整左右塞碰库和球球摩擦偏移。
- 耦合多接触、贴球堆与持续挤压接触明确暂不支持，不能用于标准开球球堆。
- 默认摩擦和恢复系数未通过真实中八桌标定。
- 袋口大小、弧度、搁板及落球边界还需要同一桌型的可靠图纸。85 mm 厂家标称值不足以确定整个袋口曲线，详见 `docs/中八器材规格核查.md`。
