# 中八规则对局与自由球台

2026-10-20。在第四阶段走位反算之前交付的增补功能。

## 规则依据

采用中国台球协会公开的[《中式台球竞赛总则（2017 年 1 月修订）》](https://cbsa.cssf.net.cn/annoucement/2017/0120/142126.html)，规则版本标识为 `cbsa-2017-01`。这是明确选择的公开版本，不宣称等同所有当前商业赛事。没有混入美式八球的指定袋规则或其他赛事的开球附加条件。

规则台型内沿 2540 × 1270 mm，球径 57.15 mm；开球线距底库 635 mm，置球点距顶库 635 mm。8 号在第三排中央，三角形底角一全色一花色，15 球彼此紧贴。原自由练习的 2540 × 1260 mm 乔氏公开台型仍保留，两种配置分别验证。

| 系统处理 | 规则第三部分条款 |
|---|---|
| 开球及不满足条件时的选择、重开警告 | 5 |
| 开球进 8 后重置，必要时由对手选择 | 5.4、18 |
| 开放球局、合法首碰后确定球组 | 7、9、10 |
| 触球后进袋/有效碰库、贴球及贴库球 | 9、13、15 |
| 犯规换手，按情况给线后或全台自由球 | 5、21、22 |
| 合法打 8 胜、提前进 8 或进 8 伴犯规负 | 1、23、27 |

本界面为本地双人、非限时对局，首局开球方可选，后续交替开球。没有模拟比球、人体动作、连击动作、跳球、飞出台面、纪律裁判和外界干扰；僵局及“未尽力击球”这类需要主观裁判的情形尚未自动判定。物理计算未完成时不作规则判罚、不推进对局。

## 使用与数据

页面顶部切换「中八规则对局」「自由球台」。规则模式显示双方球组、剩余球、比分和判罚依据；自由球只能由持有球权的一方摆白球，服务端检查摆放范围、球间重叠和袋口净空。正式出杆后不能撤回改球；预览不影响对局。只有出杆参数传给裁判接口，球位、轮次、球组和比分由后端维护，重复或过期请求拒绝。

对局自动保存于 `artifacts/rules/matches/`，刷新页面或重启同版本服务后可继续；浏览器记录最近的对局编号。导出的是对局记录，不开放任意 JSON 改写规则局面。新对局不会删除旧存档。自由练习仍可导入导出完整场景。

自由球台支持 0–15 颗不同编号目标球，既可输入数量，也可勾选具体球号；白球位置用毫米输入，生成后仍可拖动各球或输入坐标。目标球分散摆放采用可复现的种子，拒绝非法白球位置。

## 多球物理与范围

新增 `cluster.py`：同时相贴的球使用投影冲量迭代，按球号稳定排序，满足不穿透和冲量约束。与库边相连的网络交替应用球球网络及已有被动球库冲量，直到接触分离。它是确定性的刚体多次冲量工程近似，不是经过高速摄影标定的球堆弹性形变模型。

持续球球接触采用不超过 2 ms 的支撑步，并做保持质心的位置投影。其余孤立碰撞和自由运动保留连续检测、解析运动。界面回放直接采样求解记录，不按动画帧率重算。持续贴库等尚不支持的情形仍会明确停止，保留原对局。没有用假开球动画或人为球间隙绕过紧密球堆。

碰撞候选筛选使用保守位移上界，连同加速度考虑曲线路径；距离上界以外的袋角不再解四次方程，具体命中仍由原连续检测计算。多球场景移动瞄准时显示即时首段参考，点击预览/出杆才算整杆，避免拖动一次重复计算十五球。

物理配置版本为 `general-pool-spin-v2-cluster`。旧版本练习场景按既有机制备份，不静默更换模型参数。球袋几何和此前验收的台呢/球库系数保持原配置，袋角曲率仍为工程近似。

## 自验

- 400 项 Python 测试通过，包含规则分支、标准摆球、真实十五球正冲/偏冲、冲量守恒与被动性、接口和本机存档恢复。
- 8 项 JavaScript 测试通过；84 组同步瞄准与引擎的球心位置对照通过，最大差约 4.446e-15 m。
- 108 组已发表碰撞公式控制实验、6 组旋转实验和 10 个练习预设通过，阶段 A 历史材料可重新生成。
- 浏览器实测 0 球、15 球、正常开球、错误线后摆球拒绝、弱开球选择、自由球摆放及存档恢复；界面截图存于本机 `artifacts/rules/`。

这些检查验证声明模型及规则实现，不代替实桌标定。第四阶段反算未开始，等待本次增补验收。
