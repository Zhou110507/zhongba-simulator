# 台呢阻力与力度范围复核

2026-10-20。阶段 B v2，应用 `phase-b-playable-v2`，模型签名 `fe0bce6872b017b4`。针对“球走不远、低杆显效太早”返修；用户允许采用任意可靠球桌资料及有记录的微调，不限定乔氏或利百文。

## 结论与改动

主要问题是旧 UI 力度范围过窄：杆头上限只有 1.8 m/s，50% 中杆白球初速约 1.19 m/s；偏低击点在相同杆速下初速更低，倒旋在较长距离上会提前耗尽。旧 18 cm 球心间距低杆预设又过短，触球后很快回拉本来就是近距离低杆的正常结果，不能拿它代表中远距离手感。

本次将练习台杆头范围扩大到 0～5 m/s（界面可选 5%～100%）。经用户进一步要求，补查实际杆速后确认该上限接近一组冲球样本，作为保守的软件封顶，不能称为人体绝对极限。中距离高低杆预设改为 75 cm 球心间距，并增加“中力走台 · 单球”。高低杆仍由同一冲量与台面接触模型计算，没有添加回拉延迟、碰后加速或人造轨迹。

台呢改用独立的通用配置 `general_pool_cloth_v1`：

| 参数 | 旧值 | 当前值 | 依据 |
| --- | ---: | ---: | --- |
| 滑动摩擦 μs | 0.20 | 0.18 | Mathavan 实验区间低端的取整参考 |
| 滚动减速度 / g | 0.010 | 0.007 | Alciatore 公布范围内、偏快台面的工程选值 |
| 竖直轴侧旋减速度 | 10 rad/s² | 10 rad/s² | 保留；不用于衰减高低杆水平轴旋转 |
| 杆头速度上限 | 1.8 m/s | 5.0 m/s | 让常用中力与强力覆盖公开球速参考 |

阶段 A 的默认参数与离线复核保持 v3 历史基准；练习台显式选择新配置。球球和球库系数未随本次反馈任意修改。新模型签名防止旧场景被悄悄套用新动力学；浏览器发现旧场景时保存在本机 `.backup` 后提示更新，原导出文件不改写。

## 数据来源与定义

1. [Mathavan 等，2010，§3.2](https://drdavepoolinfo.com/physics_articles/Mathavan_IMechE_2010.pdf)：高速摄影实测的斯诺克球与台呢滑动摩擦为 0.178～0.245，文中采用 0.212。0.18 是参考这一区间低端的移用值，不称为中八某品牌实测值。旧 0.20 并未远离真实滑动摩擦量级，因此不能把它降到滚动阻力的量级来掩盖出杆速度不足。
2. [Alciatore 台球物性参考](https://drdavepoolinfo.com/faq/physics/physical-properties/)：pool 滚动阻力约 0.005～0.015、滑动摩擦约 0.15～0.4（常用 0.2），侧旋角减速度约 5～15 rad/s²。0.007 是在该范围内明确记录的手感调整，并非某张球桌新测得的数据。
3. [Alciatore TP B.6](https://drdavepoolinfo.com/technical_proofs/new/TP_B-6.pdf)：典型中速 7 mph（3.13 m/s）、快球 12 mph（5.36 m/s）。新界面 50% 中杆约 3.30 m/s、75% 约 4.95 m/s；皮头恢复参数维持 0.75。力度百分比属于本软件映射，不等于人体发力百分比。
4. [Alciatore TP B.8，低杆推导](https://drdavepoolinfo.com/technical_proofs/new/TP_B-8.pdf)：用于独立检查低杆碰前的速度与旋转变化。球从出杆到撞目标球前须先消耗倒旋；触球后的回拉由剩余倒旋决定。

### 出杆速度与冲球上限的直接核验

不能把白球初速当成杆头速度，也不能仅凭动画的行程反推杆速。此次增加三项直接测杆运动的资料，完整样本和单位记录在 `configs/prototype_play.json` 的 `stroke_reference` 中：

- [Kong 等，ISB/JSB 2023，P01-30](https://media.isbweb.org/images/documents/2025/archive_matterials_challis/fukuoka2023/isb_jsb2023_program_-_abstract_book_compressed_part2.pdf#page=114)，印刷页 614：22 名男性在役球员，每人 8 次九球冲球，250 Hz 动作捕捉。触球时杆头速度均值 **4.7 m/s、标准差 0.5 m/s**。这是群体均值与离散程度，不是最小/最大值；不能写成“所有冲球都在 4.2～5.2 m/s”。原页已下载并渲染核查，副本在忽略目录 `artifacts/cloth-v1/`。
- [Kornfeind 等，2015](https://doi.org/10.1016/j.proeng.2015.07.240)，20 位高水平 pool 球员、18 项跟进/拉杆/定杆/冲球任务，讨论指出极限高杆与低杆的杆速约 **4.5 m/s**。这指极限杆法，不代表一般轻球。
- [Song 等，斯诺克杆法研究 Table 2](https://sprinz.aut.ac.nz/__data/assets/pdf_file/0020/202943/067_1391_Song.pdf)：8 名专业选手的指定走位任务，高杆杆速 **2.52 ± 1.21 m/s**，低杆 **3.69 ± 0.61 m/s**。桌型、任务和样本不同，仅作为普通杆法量级交叉对照，不能与上一研究合并成统一人群统计。

据此保留 **5 m/s** 的保守应用上限，界面高端明确标为“冲球级”。约 1～3 m/s 用作常用练习档、3～4.5 m/s 用作强杆档；这些档位是便于练习的软件划分，并非文献给出的严格边界。50% 为杆头 2.50 m/s，中心击球的白球约 3.30 m/s。用户提出核验后没有继续上调速度。完整球堆冲球仍未支持，“冲球级”只表示可输入的杆速量级。

这里 `rolling_friction` 定义为**有效线性减速度除以 g**，滚动阶段 `a = −μr g v/|v|`，不是直接把某篇文献的力比或有长度单位的滚阻量填进来。滑动与滚动是两种不同损耗；滚动阻力小不代表倒旋可以无损保留。

## 分离变量复验

运行 `python -m tools.audit_cloth`，结果存入 `artifacts/cloth-v1/comparison.json`。相同的 50% 力度，单球从 (0.4, 0.42) m 沿长台方向出杆，击点 +0.4 R 以自然滚动发球；使用真实尺寸、当前六袋几何及库边模型：

| 对照 | 总行程 / m | 碰库数 |
| --- | ---: | ---: |
| 旧力度 + 旧台呢 | 2.886 | 1 |
| 仅改台呢 | 3.516 | 1 |
| 仅扩大力度 | 7.315 | 3 |
| 当前力度 + 当前台呢 | 7.887 | 3 |

这说明单独降低台呢阻力无法解决原来的力度尺度问题。当前同一线路 25% / 50% / 75% / 100% 的行程分别为 4.923 / 7.887 / 9.898 / 12.126 m，分别碰 2 / 3 / 4 / 5 库，均自然停止。

一米球心间距、−0.5 R 击点、70% 力度的轴向低杆对照：旧版碰前已转为正旋，停点在接触点前方约 17 mm；新版碰前仍有约 −86.17 rad/s 倒旋。为排除库边影响，在足够大的虚拟台面上新版从接触点拉回约 3.273 m。这个数字用于模型对照，不表示中八球桌上能忽略库边直接拉回相同距离。

在**固定同一个 1 m/s 纯滚动初态**下，无库理论停止距离从 5.097 m 变为 7.281 m，停止时间从 10.194 s 变为 14.562 s。该对照只检验台呢参数，不混入力度变化。

## 验证结果与实际操作

180 项测试全部通过，保留原阶段 A 的 122 项；新增检查覆盖：一米低杆碰前速度/倒旋与独立解析式相符、无碰撞低杆不会自行掉头、中力多库走台、固定初速停止距离，以及满力度下不同方向/击点的完整结束与合法停点。七个预设均自然结束且导入可复现；前端 JavaScript 语法检查通过。

浏览器实际试打“中力走台”：50% 杆头 2.50 m/s、白球 2.53 m/s，事件记录在 0.843、2.464、6.023 s 碰库，10.849 s 停止。中距离低杆以 0.5 倍速查看，白球触球后能明显拉回；继续检查偏角低杆路线、高杆、下一杆及模型更新提示。截图在 `artifacts/cloth-v1/`。

## 球与台面的比例复核

用户另提出球的视觉大小疑问。本次重新核对 [CBSA 球径](https://cbsa.cssf.net.cn/annoucement/2017/0120/142126.html)为 57.15 mm，以及[乔氏公开内沿](https://www.joybilliard.com/billiards-table/) 2540 × 1260 mm。长边为 44.444 个球径，短边约 22.047 个球径；不能用球桌外框尺寸与画面可玩内沿混比。

`web/app.js` 的台面坐标与 `drawBall` 共用 `transform().scale`，球半径直接取物理状态的 28.575 mm，没有放大系数。浏览器实测 Canvas 位图 1600 × 900、CSS 859 × 483.1875，横纵缩放完全相同；对应台面长约 762.90 CSS px，球直径约 17.17 CSS px。比例无误，保留球径与台面绘制。

这次完成的是有来源、可分离复验的通用手感修正；没有取得某一真实球桌的整套联合标定样本，不能将仿真结果称为实测精度。后续可以用同一张实桌的固定初速滚动距离、倒旋衰减及碰库视频继续拟合。
