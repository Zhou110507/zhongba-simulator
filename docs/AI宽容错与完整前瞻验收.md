# AI 宽容错与完整前瞻验收

版本 `wide-margin-full-horizon-v9`，基于 `111b978e788ad506f6ae87f9583f9a357941ed37`。本轮按用户反馈修正上一版减少在线预算、偏爱短路线的问题，并进一步降低借袋角控白球的优先级。

## 前瞻与复用

普通目标保留三杆，残局保留本组剩余球加黑八的深度。先建立完整深度的种子路线，再拓宽候选；已验证的多杆路线不能被仅因代价低的一杆路线覆盖，完整清台仍优先。恢复前台 30 秒／1,800 次、队尾 24 秒／1,500 次预算，取消上一版候选尝试量缩减。预算不足时用同一候选缓存继续一次，前台最多扩至 60 秒／3,600 次，目标深度不变；取消请求立即停止。

保留原有第 1 杆执行期间从第 3 杆预测停点补第 4 杆的队列机制。初次规划扩展预算时同样保留已验证前缀，直接从其预测终点补缺少的杆，不重新拓宽根局面。单次搜索新增精确出杆候选缓存和扰动检查缓存，键包含完整台面与规则状态；未完成的检查不能缓存为确定失败。参数或规划策略变化会令旧队列失效。

不能保证任意局面都存在满足要求的三杆进攻路线。界面明确区分要求深度、实际验证深度、预算不足和未找到更长的宽容错续接，不伪造后续杆。

## 人类可复刻性

增加当前进球难度和狭窄瞄准窗口的代价。每个进攻候选实际模拟方向 ±0.10°、杆头速度 ±3% 的四项独立探针，须全部合法进球，并至少三项保留舒服续接。继续遵守后斯诺、贴库高杆、普通杆速和五库范围；多库和适度杆法仍然允许，不能为了少走库而留下精确薄球。

排除无必要的借碰其他球停白球候选。必要 K 球须新打开本组球进攻线路，且四项都保留舒服续接；仍收取明显碰球风险代价。防守排序也增加碰球及袋角控球风险，能直接打到时使用直打防守，打不到才解球的原有含义保持。

对白球每次碰袋角增加 4.0 风险代价，对目标球碰袋角额外增加 0.45。保留原有空心进袋偏好和偏袋口探索，确有收益且容错足够的碰袋角路线仍可参与比较。没有降低袋角风险惩罚而反向增加推荐比例。

阈值和评分是工程偏好，四项离散检查并非完整误差分布，也不代表真人成功率。物理、台面／球尺寸及杆头速度到白球速度映射没有改变。

## 训练与验证

重新生成并复核 288 个布局、7,868 条记录、52,269 次物理模拟，训练 1,600 轮，验证集选择第 260 轮。919 条名义进球但续接脆弱的样本被改为零效用，最终 473 条正效用样本。独立测试的前四候选效用为 0.063286，固定顺序为 0.063687，未证明学习排序提高；因此只用排序先验调整尝试顺序，不削减原候选探索。数据哈希、参数和复现命令见 [训练说明](../training/ai_stage5/README.md)。

`python -m tools.audit_wide_margin` 独立验证三局，均未用于本轮离线训练；本项复验深度上限固定为三杆。结果见 [原始记录](../validation/wide_margin_v9.json)。

反馈局面用同缓存继续过一次，仍只找到一杆满足新约束的进攻；如实记录未找到更长宽容错续接。不能用另外两局达到三杆掩盖这一限制，亦不宣称本轮提速。全部推荐杆的四项探针均进球，舒服续接至少三项通过。

初次全量 **603 项 Python 测试、46 项前端测试通过**，含真实规则下四杆清台、逐杆正式执行、队尾补黑八且不重算已验证前序杆、四档出杆误差、无效终态剔除与对局不误提交。界面复验后增加预测终点续算，相关重点 49 项再通过；最终前缀保留、取消处理、预算及无效停球回归 14 项通过（新增一项回归后 Python 总数为 604，本轮未重复执行整个全量集合）。旧多库／K 球的名义合法效果保留，但其精确碰撞依赖不能再凭“模拟能进”通过推荐。旧袋角案例名义进球，四项探针只通过两项，现被排除。前端验证前瞻深度、袋角风险和逐杆容错显示。

## 实际界面执行

重启服务后在独立三球加黑八练习局使用最强档验收。33.87 秒、960 次模拟给出 `3 → 1 → 2` 三杆，三杆均为四项进球、四项舒服续接，无白球借碰和袋角控位；黑八未获验证，因此明确显示 3／4。正式执行首杆合法进 3 号球，球位符合预测，下一次查看思路直接复用 `1 → 2`，显示 0 次新模拟、0 秒。没有重新抽样直到获得清台。见 [界面执行记录](../validation/wide_margin_ui_v9.json)。
