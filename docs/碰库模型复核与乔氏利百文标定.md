# 06 碰库场景：底层复核、修正与标定边界

本文件为 v2 历史复核记录，表中的 0.80 和角度属于当时配置。当前 v3 已调整能量恢复参数并补充 05 归因及独立实现对照，最新数值见 `05薄厚球碰库专项复核.md`。

日期：2026-10-19。当前为阶段 A 返修，等待用户重新验收。标定目标已由用户确定为**乔氏球桌 + 利百文台呢**；尚未取得该组合的实测动力学数据。

## 结论

旧版确有模型缺项：台呢运动已经包含旋转，但库边碰撞只做法向速度反转并乘 0.8，三轴旋转完全不变。旋转与库边接触的处理不完整，导致旧前旋在反弹后继续把球明显拉向库边。此前 76 项测试只证明旧模型内部的数学一致性，没有证明其反弹角接近真实球桌；原“自行验收通过”对此说明不足。

本次已替换为包含库边摩擦、台呢接触反力、两处切向冲量及三维旋转变化的模型，同时保留旧模型作诊断对照。改进的是物理响应，未通过手工压平轨迹或强制反射角相等修改画面。

## 原 06 的完整初态

| 量 | 数值 |
| --- | --- |
| 球心位置 | x=1.8000 m，y=0.6500 m |
| 球心速度 | vx=2.2000 m/s，vy=0.7000 m/s |
| 角速度 | ωx=−24.49694，ωy=76.99038，ωz=20.00000 rad/s |
| 球半径 | 0.028575 m |
| 台呢接触点滑速 | u=(vx−Rωy, vy+Rωx)=(0,0) |

因此，这个场景是**自然滚动并带侧旋**，不是无旋转。ωz 是侧旋；ωx、ωy 使球自然滚动。初始侧旋在理想水平台面的模型中不造成自由运动弯曲。第一段为直线；所有新旧对照都保持相同初态和原测试台尺寸，以隔离此次碰库修正。

## 旧曲线从哪里来

首次碰右库发生于 t≈0.325628 s。入射速度约为 (2.169560, 0.690314) m/s，水平旋转约为 (−24.15799, 75.92510) rad/s。

旧碰库只将 vx 改成 −1.735648 m/s，其他速度和旋转不变。此时台呢滑速约为 (−3.905207, 0) m/s，摩擦加速度约为 (+1.962, 0) m/s²。它不与出射速度平行，位置二次方程自然形成弧线；球尚未恢复滚动就再次碰到上库。故旧弧线的直接来源是“保留的旧旋转 + 碰后滑动摩擦”，不能解释为已经正确模拟了库边吃塞。

绘图也已调整：逐个解析运动分段绘制，并保留碰撞顶点；不再只把固定 60 Hz 点跨碰撞直接连起来。橙色标出满足 `vx*ay−vy*ax ≠ 0` 的弯曲滑动段。没有使用贝塞尔平滑或人工转弯。

## 新碰库模型

参考 [Mathavan、Jackson、Parkin（2010）原论文](https://doi.org/10.1243/09544062JMES1964)的双接触冲量分析：把球与库边、球与台呢作为两处接触，同时计算平动、三轴旋转和摩擦。压缩阶段积累法向功，恢复阶段返回其 e² 倍；每步切向冲量受库仑摩擦上限约束，接近零滑速时防止数值过冲。

这是本项目独立编写的分裂冲量近似，不宣称已逐式复现论文的完整数值求解器，也未完成真实乔氏桌验证。保留二维球心约束；可能离台或复杂多接触的情况仍不在当前适用范围内。

原 06 首次碰库的核查结果（角度均相对库边法线）：

| 项目 | 旧模型 | 新模型，512 步 |
| --- | --- | --- |
| 入射角 | 17.65012° | 17.65012° |
| 碰后瞬时角 | 21.68906° | 10.61534° |
| 恢复滚动后的方向角 | 恢复前已再次碰库 | 16.64996° |
| 碰后 ωy | 75.92510 rad/s，完全未变 | 17.95905 rad/s |
| 碰后 ωz | 16.74372 rad/s，完全未变 | −13.45130 rad/s |

瞬时反弹方向和后续滑动结束方向不同，不能只取其中一个角度代表整段路线。新模型仍可能产生短暂弧线，这是接触点滑动摩擦的结果。严格的入射角等于反射角对应完全弹性、无摩擦的理想对照，而普通带滚动或侧旋的碰库不应被强制满足这一条件。

把冲量步数从 512 增至 1024、2048 后，首次瞬时角分别为 10.61594°、10.61623°，恢复滚动角分别为 16.65016°、16.65025°，变化随加密减小。原始证据见 `artifacts/phase-a/cushion-audit.json`；原始 v1 回放数据保存在 `cushion-before.json`。

## 真实乔氏 + 利百文的标定流程

1. **记录器材与条件**：具体桌型、利百文型号及新旧程度、球型号/清洁状态、胶边型号和鼻尖接触高度，记录台呢方向、温湿度、调平情况及视频尺度。
2. **纯滚动减速**：在无碰撞直线段测量位置与时间，先确认已无滑动，再拟合减速度；有效滚动参数为 a/g。不同速度、顺逆台呢及横纵方向分开检查。
3. **滑动与旋转**：用有标记的白球同时跟踪平动和旋转，确认滑动段；仅在没有其他接触力的滑动区间拟合 μs。不要把整个滚动停止距离直接拿来拟合滑动摩擦。
4. **自旋衰减**：测原地侧旋或已知平动情况下的 ωz 随时间变化。
5. **库边联合标定**：采集不同速度、入射角、前后旋与左右塞的碰库；比较碰前、碰后瞬时、恢复滚动后三组状态，联合拟合库边参数。带摩擦与旋转时，不能简单用两次总速度之比作为恢复系数。
6. **独立验证**：保留未参与拟合的场景和角度，报告轨迹、角度、速度与停点误差。若误差随速度、台呢方向或库边位置有系统变化，再扩展模型，而非继续调一个全局常数。

在取得上述实测资料之前，本次交付只能称为“旋转耦合更完整、经过数值验证的研究仿真”，不能称为已达到指定乔氏球桌真实精度。
