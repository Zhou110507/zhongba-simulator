# AI 进球与走位平衡 v3

本轮按用户反馈重新训练：好球需要同时考虑本杆进球与后续衔接。不能因为走位少一库或杆法轻，就接受下一杆贴库、目标球长距离入袋等明显代价；也不能为追求简单进球无视走位执行难度。

## 已落实的变化

| 项目 | v2 | v3 |
|---|---|---|
| 白球走库 | 最多两库 | 最多五库；库数是小幅软代价 |
| 杆法探索 | 以中杆和少数高低杆为主，无侧塞 | 交错搜索轻/强、高/低和适度左右塞，仍受既有击点圆盘约束 |
| 走位代价 | 杆速、击点、库数惩罚较强 | 保留代价，以更好的下一球抵消适度复杂度 |
| 后续评价 | 主要进球几何容错 | 加强两段距离、手架/近库、长目标球路程和最难一杆评价 |
| 入袋方式 | 未单独标注袋角 | 实际袋角碰撞与横向偏移有小额代价，保留偏袋心线路 |
| 多球前瞻 | 两杆 | 三杆，实际每杆重算；三球以内尽量规划至黑八 |
| 训练局面 | 1–3颗本组球 | 1–5颗，两种球组；另做全组七球逐杆重算练习 |

仍保持后斯诺、后方近库高杆与二次击打排除。杆头探索上限3.2 m/s是原5 m/s手动范围内的搜索选择，没有改变白球速度映射，也没有改变开球杆速、尺寸或物理。

评分定义、工程阈值和参考资料见 [训练包](../training/ai_stage2/README.md)。多库不自动意味着好球，空心不自动压过有益的借袋角；所有推荐都要在原物理与规则下验证。

## 反馈案例复盘

用户提供的 `AI清台思路 (5).json` 保留原始球位并从训练中留出。旧版先打2号后，白球停在距右库约48 mm的位置，下一杆1号需要高杆并将目标球送往约1727 mm外的左上角袋。该路线在模拟中进球，但不足以说明衔接舒服。

本轮用 `tools/evaluate_ai_feedback.py` 对新旧路线使用同一物理和同一评分口径实际逐杆复盘，原始结果见 `training/ai_stage2/feedback-comparison.json`；不会将不同版本的原始cost直接当作同一指标比较。

## 实际训练与练习

训练是26输入价值网络的实际梯度更新，1600轮、验证集选权重；数据按初始布局隔离。训练完成后冻结权重，独立执行两类检查：等预算基础/模型搜索比较，以及每一杆实际提交后重新规划的连续练习。练习包括全组七球和用户反馈局面，并保留失败与中断，未将验收结果回灌到本轮训练。

网络分数不是人类成功率，微扰也不是人类成功率。没有从职业比赛录像提取数据；侧塞沿用现有二维模型，尚需实桌校准。复杂球堆、解堆、防守和抬杆仍有限，不能声称职业水平或任意局面必清。

## 在中八对局中使用

1. 进入“中八规则对局”，在“对局方式”选择任意一方为AI，正常开局和残局共用该模型。
2. 可先看“AI思路”再执行，也可勾选“自动对打”；暂停或改回本地双人即可接管。
3. 自定义残局可自由摆球，完成后分析。导出的思路保留原始球位、球组、模型和实际杆法信息。
4. 页面逐杆显示白球库数、左右塞和目标球是否碰过袋角；未碰袋角不等同于绝对正袋心，横向偏移保留在JSON中。

AI通过原对局服务提交动作，绑定对局ID与revision；重复提交、取消和过期任务不能再次执行。不改变原练习台、反算和手动出杆功能。

## 验证记录

- 实际生成240个训练/留出布局，88,213次物理模拟，1,266条价值样本、516个首杆分支。分支中有169杆三库、50杆四库、14杆五库，356杆使用侧击点，162杆涉及目标球袋角接触；不是只修改“允许”参数而没有生成相应训练样本。
- 网络训练1600轮，验证集选择第140轮。训练/验证/测试分别160/40/40个初始布局；测试149条样本，模拟价值MSE 0.01812，训练均值常数基线0.07273。数据指纹 `4aea7dbed723981f4c381bb4e6cc9b0c06829a9993d663c88307a35401dc7886`。
- 固定测试候选集中，基础/训练排序均清台25个；独立种子78001–78008，双方同为1800次模拟/30秒预算，均找到7条路线、清台6个，平均工程难度2.8892。没有证据证明网络排序独立带来明显提升；本轮反馈改善包含候选范围与评分调整的作用。
- 冻结模型逐杆练习：种子68001–68024，加用户留出案例，共25局、19局清台；其中6个整组七球＋黑八、另有两颗对手球的布局均清台，全色/花色各3个。91杆全部实际提交并逐杆核对停点和规则，含21杆至少三库、27杆侧塞、82杆未碰袋角入袋。六局未清台如实保留，未用其结果重训。场景并非职业比赛录像或十五球满台对抗。
- 练习中仍有15杆目标球路程超过1.2 m、7杆后方近库受限，说明还有不够舒服的打法；不能把清台次数直接当作“人类好打程度”的充分证明。
- 用户案例：旧路线2→1→3→8，新路线3→2→1→8；同一评分口径下最难一杆工程代价由6.0279变为2.1914，平均2.6812变为1.6030。旧版1号目标球路程1727 mm、后方近库；新版1号改进右上角袋，目标球路程832 mm，后方不受近库限制。新版首杆白球走三库，1号杆用了适度左塞。这里的代价是工程指标，不能换算为真人概率。
- 原功能515项Python测试、新模型/约束/清台30项、标准十五球AI开球1项、实际HTTP思考并执行黑八及重复提交保护1项，合计547项分组通过；JavaScript36项通过。浏览器实际导入用户案例、执行三库首杆、自动连续重算并合法打进黑八获胜，页面无脚本错误。
- 中八规则对局已使用 `short-runout-value-v3`；本轮验收服务为 `http://127.0.0.1:8772/`。原物理、规格和力度映射没有修改。待用户验收本轮走位与进球的平衡，再处理反馈。
