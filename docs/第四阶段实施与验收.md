# 第四阶段：自由球台走位反算

2026-10-20。阶段 D 基础范围已实现，提交用户验收；阶段 E 的复杂线路全局搜索尚未实施。

## 使用与入口

仍使用原来的“自由球台”。顶部展开 1–15 号球选择；“目标球个数 · 0–15”不含白球。“一键摆满15球”立即生成十五颗目标球和一颗白球，当前数量显示在按钮旁。可以只留白球；此时不提供反算目标。

球台右侧增加“走位反算”：选择直接首碰的目标球、可选进袋条件，指定白球最终球心及容差圆。输入毫米坐标，或点击“在球台上选终点”后在球台选点；选点不改变出杆方向。可限制白球碰库次数、是否允许白球再碰其他球，预算提供 6、12、25 秒。白球与同一目标球可能再碰，结果中的“触球次数”会明确显示，所有后续碰撞都影响最终停点。

“载入走位示例”设置 1 号球进右上角袋、白球最终停在 (1600, 500) mm、半径 60 mm、白球零库的任务。每次都实际搜索与复验，没有预置推荐答案。

结果最多保留三个不同杆法，显示方向、杆头速度、对应软件力度、击点、白球初速、最终位置、误差、碰库、触球与进袋信息。“应用并预览”只应用出杆参数，整桌球位保持，调用普通 `/api/shot`。出杆、回放、保存场景继续使用原流程。中八规则模式不提供本反算面板，仍自动判罚继续、关闭全部球尾迹。

## 计算与硬性条件

- 用目标球接触圆参数化直击角度，组合当前杆法、不同厚薄、杆速、高低杆、袋位几何种子，以及四维 Halton 采样。
- 对多个优良起点进行有界坐标搜索、缩小步长；球杆击点始终位于 0.55 R 圆盘内，杆速 0.25–5 m/s。局部搜索仍可能漏解。
- 每次候选均保留当前场景中的全部球，并调用 `strike`、`engine.simulate`、同一球球/球库/台呢/球袋模型。没有为反算改变尺寸、摩擦、杆速或碰撞系数。
- 只将**完整停球、直接首碰指定球、白球未落袋、满足碰库/其他触球/指定进袋限制**的候选作为可用方案。硬性失败优先于误差排序，不能用一个靠近终点的犯规/错误碰球方案抵消。
- 候选筛选阶段省略轨迹段分配及 JSON 序列化，保留物理状态与事件；推荐前从原始球位重新运行完整轨迹版本。关闭轨迹记录的结果不得用来回放。
- 前三条方案的参数过近时合并。首方案在剩余预算内检查方向 ±0.05°、杆速 ±2% 的最多四组微扰。显示的是模型扰动是否仍满足条件，不是实战成功率；未测完整四组会显示实际分母。
- 网页每个任务最多 480 次前向计算，包含重新复验与微扰。API 最大 1000 次、最长 30 秒。预留复验时间；尚未完成的计算不会推荐。

搜索思路的参考文档：[SciPy Halton 定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.qmc.Halton.html)、[SciPy 无导数优化与自定义优化示例](https://docs.scipy.org/doc/scipy/tutorial/optimize.html)。本项目自行实现有限采样与坐标搜索，未引入 SciPy，也未采用其完整全局优化器。采样只用于寻找候选，不提供全局最优或可达性证明。

## 后台运行、取消与结果有效期

新增 `/api/plan/start`、`status`、`cancel` 三个本机 JSON 接口，沿用 Host、Origin、体积与有限数值检查。单个反算工作线程与普通出杆共享两个计算槽，仅允许一个反算任务；进度和取消接口不等待计算槽。最多保留 20 条任务、15 分钟记录。

搜索检查取消与单调时钟预算，运动事件和 Hertz 微步均可协作中断。改变球位、切换规则模式或正式出杆会取消原任务；普通调方向不会发起新反算。球位、模型或任务变化后旧结果作废，异步启动/结果晚到不能覆盖新局面。后台搜索不驱动画布逐帧全量重算。

返回状态分别是找到范围内方案、仅有范围外近似、预算内未找到、前向计算均未完成、已取消或服务错误。**未找到不代表物理不可达。** 当前只搜索直接首碰指定球的方向，首碰后碰库可参与验证；复杂多库路线、多杆规划、跳球/扎杆不属于本阶段。实桌参数尚未联合标定，数值停点误差不等同于实桌精度。

## 自行验收

- 全量 **474 项 Python**、**25 项 JavaScript** 通过。新增反算与接口 26 项 Python，新增异步失效/模式取消/保持球位的方案应用 4 项 JavaScript。
- 低杆停点、高杆场景停点、角袋进球加定点三类任务均从不同的初始杆法搜索，在 60 mm 容差内找到方案；每一条推荐再通过普通出杆接口核对最终坐标与进袋。
- 320 次上限基准中，三类最佳误差分别约 **1.2、1.7、4.5 mm**；本机运行约 **2.8–3.6 秒**。这些是二维模型自洽性案例，不能推广成任意布局或实桌精度保证。具体结果受时间预算与运行负载影响。
- 验证球位不可变、十五目标球全部传入每次前向计算、遮挡球为硬失败、零误差仍不能抵消错误首碰、进袋/非法输入/无目标球/无效终点被拒绝、预算未找到与不可达分开。
- 三球 Hertz 接触网络的完整/轻记录版本，其最终状态、事件、时长完全相同；验证飞行前和接触微步中的取消，以及任务结束后计算槽归还。
- 浏览器实际生成 **16 / 16 球在台**，反算目标列表覆盖 1–15 号；搜索期间可调方向和取消；应用方案后普通预览仍显示同一停点。检查球位变化作废方案、终点选取与瞄准区分、规则模式不显示反算且仍无尾迹。
- 84 组同步瞄准对照仍与物理内核一致；108 组公式控制与六组旋转实验仍通过；十个练习预设均完整停球且可复现。

用户验收建议：先点击“一键摆满15球”确认数量和球号；再“载入走位示例 → 计算走位 → 应用并预览”，观察目标球入袋和白球终点；最后尝试自由布局与取消任务。
