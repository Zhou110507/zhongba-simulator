2026-10-20。第二阶段已由用户验收；本阶段已实现并自验，待用户验收。应用 `phase-c-spin-v1`，模型签名 `161dffdaa97c416c`。第四阶段走位反算尚未开始。

## 实现内容及依据

新增球球摩擦模块 `billiards/ball_contact.py`。使用实际接触法线与球面接触点的相对滑速计算切向冲量，更新两球平动和绕 z 轴侧旋；恢复系数仍为 0.95。三维球面滑速同时考虑高低旋和侧旋，摩擦随滑速增大而降低；水平摩擦受库仑上限与不反转相对滑动的运动学上限共同限制。

摩擦参考为 [Alciatore TP A.14](https://drdavepoolinfo.com/technical_proofs/new/TP_A-14.pdf) 的式 5–17 和 PDF 第 4 页拟合：μ(s)=0.009951+0.108·exp(−1.088s)，s 的单位为 m/s。原文重述 Marlow 数据并作拟合；本项目没有将其称为新获得的中八实桌数据。该文图示可用于检查速度、切角及旋转的带偏趋势。

针对本项目二维范围，解析求得水平投影冲量。两球的平动动量与总 z 角动量守恒，法向非弹性及切向摩擦消耗机械能。绕 x/y 轴旋转在球球冲量中保留；**未求解竖直冲量、离台或高低旋向目标球的转移**。高低旋仍通过既有台呢模型演化，球库保留既有双接触旋转耦合模型。此限制在模型模块、实验页、参数来源和场景版本中明确，不称为完整三维碰撞。

`Physics()` 的默认球球模型仍为无摩擦，以保护原阶段 A 的解析基准；练习台明确选择 `general_pool_spin_v1`。配置另可选择常数摩擦或速度相关拟合，相关参数进入完整快照与签名。旧场景按既有规则备份并拒绝静默混用。

## 典型数值复核

当前配置的实验初态为球速 1.341 m/s、等大球、首次接触时刻 t=0；侧旋比定义为 Rωz/v：

| 实验 | 带偏角 | 目标球碰后侧旋 |
| --- | --- | --- |
| 30° 切球，无高低旋、无侧旋 | −3.549° | +6.144 rad/s |
| 同初态，无球球摩擦对照 | 0° | 0 |
| 正碰，侧旋比 +0.5 | +3.549° | −7.095 rad/s |
| 30° 切球，齿合侧旋比 +0.5 | 约 0° | 约 0 |
| 30° 切球，自然前旋比 +1 | −1.004° | +1.736 rad/s |

符号由实际接触切向决定，不能把绝对值直接当作瞄准补偿。数值是本模型计算结果，绝非实桌测量。原低杆偏瞄 0.5° 的几何切角仍为约 6.576°；含球球摩擦后的回拉偏角约 18.436°，原无摩擦对照约 18.952°，符合新增小幅切向冲量改变碰后方向的机制。

## 标定入口

浏览器可导入 JSON、查看拟合残差与样本范围、导出估计；同样可运行：

```powershell
python -m tools.calibrate web/calibration-example.json --output artifacts/phase-c/calibration-demo.json
```

示例来源为已标注的**合成数据**，用于软件验证，不是新的真实桌面标定。支持以下独立测量种类，每类至少两条：

- `rolling_stop`：纯滚动初速与停距，v²=2μrgd；系数定义为线减速度/g。
- `slide_to_roll`：初速、球半径、带符号前旋角速度与首次恢复滚动时间，|v−Rω|=3.5μsgt；中途不得碰球或碰库。
- `spin_decay`：无碰撞时、仍在转动的初末侧旋绝对值及间隔，Δ|ωz|=αt。
- `normal_ball_collision`：两球碰前接近法向相对速度及碰后分离法向相对速度，v_sep=e·v_app。

采用过原点最小二乘回归，输出参数、各条独立比值范围及回归坐标内的残差 RMS。拒绝缺字段、非有限值、非法量级和样本不足，不悄悄丢弃离群值。导出的来源及 `estimates_only_not_applied_or_independently_verified` 状态会保留。**不把库边法向速度比当成当前库边能量恢复参数**；球库和球球摩擦曲线的联合拟合仍需适用实验数据。拟合结果不自动改写配置，也不等于独立样本精度评估。

## 自验结果

- 351 项 Python 测试通过，保留阶段 A/B 验证。覆盖不增能、平动动量和 z 角动量、60 组不同质量/旋转随机接触、左右镜像、球序交换、齿合抵消、滑动不反转以及配置输入限制。
- 108 组独立公式对照：对等大球、静止目标球、e=1 的控制实验，覆盖三档速度、四档切角、三档高低旋及三档侧旋，与原文水平带偏方程一致。该对照证明实现符合指定公式，不是新增实桌准确度证明。
- 六组实验都计算到停止，重复计算内容完全一致；十个练习预设完整结束且复现一致。
- 8 项 JavaScript 检查通过；同步瞄准对照增加至 84 组，与引擎首次事件一致，球心最大差 4.45e-15 m。
- 标定软件用独立生成的合成输入恢复预设参数；含噪停距拟合通过留出速度样本的停距预测检查。浏览器实测导入、拟合及导出，清楚显示“合成数据，非实测”。
- 浏览器检查齿合抵消、侧旋对照、左右旋碰库及主练习台更新；参数变化不复用旧图。页面无控制台错误。
