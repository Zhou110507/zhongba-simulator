# 界面视觉优化与验收

日期：2026-11-05。基线：`ae96c5680cd2a12a5b48134698b95dfd8b99a637`。

本轮使用已安装的 `design-taste-frontend` 技能，优化现有中八练习应用。页面保留实际球桌、全部训练及规则功能，采用深炭色面板、暖金色主操作、绿色台呢和统一的间距、圆角与字号。没有新增外部 CDN、字体下载或前端框架。

## 改动

- 新增独立的 `web/visual.css`，统一练习、反算和规则模式的表单、导航、卡片、状态提示、事件与回放界面。正文提示和控制标签至少 13px，出杆角度采用更大的等宽数字。
- 球台使用暖色木框、细嵌线、台呢明暗与静态织纹。绘制仍使用原有共享袋口、库边几何；装饰不参与碰撞。背景继续缓存，织纹不逐帧计算。
- 900px 及以下将出杆参数放在球桌状态之后、回放之前；手机保留完整球桌，表单与底部工具按一列排列。
- 引入设计技能原有的 `motion.css` 和 `motion.js`。按钮悬停上移 1px，按下有反馈；系统开启减少动效时停止位移。添加清晰键盘焦点、跳转球桌链接和球形图标。
- 球桌尺寸、物理参数、AI 搜索预算、规则判定与场景存储格式均沿用原实现。
