# 自然走位与离线出杆排序

本阶段保留原有进球／续接价值模型，新增一个用于出杆候选排序的小型神经网络。它在完整物理试算之前，预测哪些杆法更值得先尝试；预测本身不能批准出杆。后斯诺、近库高杆、有效停球、合法首碰和中八规则仍由原来的校验链决定。

训练覆盖 288 个合成布局，进行 17,225 次共享物理模拟，得到 7,938 条候选记录，训练 1,600 轮，由验证集选择第 1,320 轮。布局内有不同目标球、球袋和高低／左右击点；未完成、无效或未进袋结果的效用为零。成功候选用 `exp(-0.20 × cost)` 作为工程效用，其中包含下一球难度、手架、距离和借碰代价。

同一个布局的记录只属于一个数据分组。无进攻候选的布局没有排序样本；运行时对此直接返回空候选集，随后按可直达性进入防守或解球，不请求神经网络处理不存在的候选。

## 数据与结果

- [shot-prior-dataset.json.gz](shot-prior-dataset.json.gz)：完整可复现记录，gzip 解压后为 UTF-8 JSON，固定压缩时间戳。解压后的 SHA-256 为 `fa2e774b1bf125d7fe042a276542a4d50fd8e02196983381e66b2394346e471f`。
- [shot-prior-training.json](shot-prior-training.json)：模型、布局划分、完整训练轨迹和验证／测试结果。
- [ai_shot_prior.json](../../configs/ai_shot_prior.json)：实际部署的参数。

独立测试集包含 1,440 条记录、80 个“布局＋目标球袋”候选组。在每组只看前四个候选时，学习排序后最佳已验证候选的平均效用为 **0.35475**，固定杆法顺序为 **0.25579**；同一候选全集的上界为 0.38196。这个指标检查有限模拟预算下能否先找到更好的候选，不是进球率、清台率或真人等级。

这仍是小规模合成训练，没有使用职业比赛视频或实桌轨迹。它不能保证对训练分布以外的任意球堆都有效，因此在线仍保留候选多样性、物理验证和有界后备搜索。

## 重训

```powershell
python -m tools.train_shot_prior --layouts 288 --workers 4
python -m tools.train_shot_prior --reuse
python -m tools.audit_human_continuation
```

训练会更新部署模型和报告。更改模型后既有 AI 缓存按模型指纹失效，避免将旧规划继续用于新模型。四档 AI 共用此规划器，出杆误差的原有差异保留。
