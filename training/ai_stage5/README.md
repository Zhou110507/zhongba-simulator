# 宽容错进球、自然走位与完整前瞻

本阶段修正上一阶段以减少在线预算换速度、较短便宜路线覆盖多杆路线的问题。普通前瞻目标仍为三杆，残局仍按本组剩余球加黑八规划；运动期间的队尾补算继续工作。搜索前台恢复到 30 秒／1,800 次，队尾为 24 秒／1,500 次；初次预算不足时用原候选缓存继续一次，不降低目标杆数。物理上未找到足够长的宽容错路线时如实报告，不能编造后续球。

## 推荐要求

- 提高当前进球难度及狭窄瞄准窗口的代价，允许适当多库、加塞换取好打的下一球。
- 每个推荐进攻候选通过方向 ±0.10°、杆头速度 ±3% 四个独立物理探针；四项必须均合法进球，至少三项保留普通出杆空间、适中距离及足够进球窗口的续接。杆速仍受原有普通杆／近库限制。
- 白球借碰其他球后精确停位不作为普通进攻走位。必要 K 球必须真正打开原本被堵的本组目标，并且四项探针均保留舒服续接。
- 降低借袋角走位的优先级：每次白球碰袋角增加 4.0 风险代价，目标球碰袋角额外增加 0.45，保留原有空心进袋偏好。并非禁止所有碰袋角入袋。

以上角度、比例、阈值和代价是用户偏好的工程定义，不是职业选手实测误差或成功率；四个离散探针也不能证明整个连续误差区间都安全。物理模型、球桌尺寸及力度映射没有更改。

## 已完成的离线训练

288 个合成布局，7,868 条候选记录。46,701 次候选模拟加 5,568 次续接复核，共 **52,269 次**。原来名义上进球的候选中有 919 条因后续落点不够稳而改为零效用；最终有 473 条正效用记录。训练 1,600 轮，验证集选择第 260 轮。训练／验证／测试按整个布局隔离。

- [完整数据](shot-prior-dataset.json.gz)，解压后 SHA-256：`83d669e6c4883eb1c0292e725c8c0e1cb6d690290f834422140852346dc30894`。
- [参数、训练轨迹与分组](shot-prior-training.json)。部署参数见 [ai_shot_prior.json](../../configs/ai_shot_prior.json)。
- 固定候选组前四项的测试效用：学习排序 0.063286，固定顺序 0.063687，上界 0.101878。**独立测试未证明排序提升**，不能称作清台率提高。学习结果仅调整尝试顺序，保留原有候选尝试数量和物理校验。

这仍是合成物理训练，未使用职业比赛视频或实桌轨迹，不能声称达到职业水平。

## 复现


训练会更新模型；模型或规划策略文件改变会使原队列指纹失效，源码更新后须重启服务。四档 AI 仍共用最高档规划，仅实际出杆误差不同。
