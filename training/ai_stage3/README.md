# AI 随机微隙开球、借碰与解球训练包 v4

本阶段在 v3 的进球／走位平衡基础上训练固定开球方案、合法二次借碰及防守解球，并加入完整路线复用和回放期间预计算。模型来自本软件的模拟，尚未用职业录像或实桌数据训练。

| 项目 | 本次实际训练与留出结果 |
|---|---|
| 开球 | 150 个固定方案 × 12 个训练球堆，1,800 次；选出两个方案，另做 24 次验证、48 次独立测试 |
| 随机球缝 | 每个球堆随机设置 0.10–0.50 mm 微隙；记录并断言实际最小球间净隙为正；三个种子集合互不重叠 |
| 开球留出 | break-133：10/24 局进球、0/24 摔袋、24/24 合法；break-76：6/24 局进球、1/24 摔袋、23/24 合法 |
| 清台价值网络 | 240 个残局、92,811 次模拟、1,329 个样本，26→12→1，训练 1,600 轮、验证集选第 240 轮 |
| 借碰训练覆盖 | 268 个含二次接触分支，其中 35 个释放本方紧邻球对；包含本方／对方球相邻布局 |
| 清台价值测试 | MSE 0.00975，恒均值基线 0.05794；固定候选集基础／网络排序均清台 29 局，未证明网络排序额外提升清台率 |
| 解球／防守价值网络 | 72 个布局、16,286 次模拟、1,388 个样本，16→12→1；训练 1,000 轮，选第 1,000 轮 |
| 解球／防守测试 | 48/12/12 个布局按布局划分训练／验证／测试，各集包含全部三类布局；测试 232 样本，MSE 0.00715，恒均值基线 0.03851 |
| 冻结整合演练 | 14 个案例、34 杆实际执行全部完成；5 次合法防守／解球，8 次走位借碰，16 次续接缓存命中，20 次预计算 |

开球测试样本很小，41.7%／25% 是模拟留出频率，不能当作实桌进球概率或宣称已达到高进球率。开球是有限动作的离线奖励筛选，不是另一个神经网络。解球标签包含有预算的对手回复搜索；价值误差不等于对局胜率。

## 文件与重现

- `break-training.json`：全部 1,872 次开球记录、随机微隙、实际最小净隙、固定方案及训练／验证／测试汇总。
- `dataset.json`、`training-report.json`：v4 清台价值数据、训练曲线、布局划分及排序对照。
- `tactics-dataset.json`、`tactics-training.json`：解球／防守特征、原始出杆、标签、训练曲线及布局种子划分。
- `integrated-audit.json`：冻结模型后的独立案例、完整初态、实际提交动作、判罚、停球位置及缓存计数。最多六杆，正常交接回合或胜负即停止；不是整局胜率测试。
- 当前权重位于 `configs/ai_value_model.json`、`configs/ai_tactics_model.json`；固定开球表位于 `configs/ai_break_model.json`。

```powershell
python -m tools.train_break --workers 4
python -m tools.train_runout --layouts 240 --workers 4
python -m tools.train_runout --reuse
python -m tools.train_tactics
```

完整生成需要较长时间。`train_runout --reuse` 可直接读取仓库内本阶段数据；训练数据 SHA-256 按 `json.dumps(data, sort_keys=True)` 的 UTF-8 字节计算。生成过程有墙钟预算，重跑数据可能受机器负载影响。

## 实战策略与边界

开球只按局号选择固定方案，使用训练所得白球点位、角度及杆法；不访问目标球坐标、当局种子或缝隙，不执行在线开球搜索。两个点位为 (500, 870) mm、(500, 160) mm，对应角度 353.1009518°、16.2680341°，均为杆头 5.0 m/s、中杆。杆头速度不是白球速度；沿用原有 5 m/s 上限与冲量映射，未修改动力学。原有摆球选项与算法不变，训练额外覆盖到 0.5 mm 微隙。

先搜索进攻，允许首碰合法目标后借碰本方、对方及黑八。提前打进黑八、首碰错误、白球摔袋等仍由原规则否决。接触每次加 0.06 代价，释放本方紧邻球对每对减 0.25（最多三对）；这是工程奖励，不是实测职业权重。保留后斯诺、后方近库高杆及二次击打风险限制，普通探索杆速上限 3.2 m/s、最多五库。

没有合适进攻时，另给解球／防守 12 秒、700 次模拟预算，候选包含首碰前 1–3 库及高低杆／侧塞。优先合法进球，再比较合法解球和防守；仅明显难打的进攻才可能让位于遮挡较好的防守。所有已验证方案都经过完整停球与原规则判定。没有任何已验证合法线路时仍给有界尝试，并标明可能犯规，不承诺一定解到。用户取消和未完成仿真不会提交半杆。

缓存校验所有球的位置、速度、旋转、落袋状态、球规格、规则回合及模型指纹，位置容差 1 微米；对手球或黑八改变也失效。匹配时复用已验证的后续杆，新增模拟为零。服务器取得本杆完整结果即启动下一杆计算，浏览器回放结束才允许执行；手动杆结束后轮到 AI 也会提前计算。物理结果只提交一次，预测不修改对局。

当前仍是二维水平出杆模型，不支持跳球、扎杆、抬杆，侧塞需实桌校准。34 杆整合演练没有触发未验证兜底，不能据此声称所有局面都能合法出杆或清台。既有练习、反算、球桌尺寸、动力学和规则保持原实现。

原则参考 [Dr. Dave 八球开球](https://drdavepoolinfo.com/faq/break/8-ball/)、[八球策略](https://drdavepoolinfo.com/faq/strategy/8-ball/)、[球堆间隙讨论](https://drdavepoolinfo.com/bd_articles/2018/march18_break_feature.pdf)。这些资料支持策略方向，不代表本项目参数来自实桌测量。
